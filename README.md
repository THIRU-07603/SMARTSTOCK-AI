# SmartStock AI

AI-powered inventory optimization and stockout prediction prototype for retail and quick-commerce.

## Run
Open `index.html` in a modern browser.

## Features
- Inventory dashboard
- Demand prediction prototype
- Stockout risk alerts
- Slow-moving and overstock detection
- Smart reorder recommendations
- Multi-store transfer suggestions
- Demo AI inventory assistant

This prototype uses deterministic mock data for hackathon demonstration.
